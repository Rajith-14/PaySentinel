# PaySentinel React + Vite Prototype

A phone-responsive hackathon prototype inspired by the uploaded Retainly visual language: warm paper background, bold black typography, lime/lavender/mint abstract blocks, thin borders and offset shadows.

## Run
```bash
npm install
npm run dev
```
Open http://localhost:5173

## Build
```bash
npm run build
```

## Vercel
Import the GitHub repository into Vercel. Framework: Vite. Build command: `npm run build`. Output directory: `dist`.

## Included
- Landing page
- Live Demo with three fraud scenarios
- Editable payment analyzer
- SMS context analyzer
- Risk history
- Technical architecture
- Responsive mobile design
- No backend required for the demonstration

The fraud scoring is simulated for the prototype. It does not access real UPI apps, real SMS, camera, bank accounts, or execute payments.
